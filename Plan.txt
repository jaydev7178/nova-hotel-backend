{
  "cartItems": {

  },

** The OrderService.createOrder() method:
- Validates stock availability
- Calculates total amount
- Creates order with PENDING status
- Creates order items
- Sends confirmation emails

2. Terms Acceptance:
** User must accept terms via PUT /api/orders/{id}/accept-terms
** System:
- Verifies order ownership
- Updates order status to APPROVED
- Updates product stock quantities
- Sets terms_accepted = true

3. Payment Process:
** Admin sends payment info: PUT /api/orders/{id}/send-payment-info
- Updates status to PAYMENT_INFO_SENT
** Admin confirms payment: PUT /api/orders/{id}/confirm-payment
- Updates status to PAYMENT_CONFIRMED

4. Delivery Process:
** Admin initiates delivery: PUT /api/orders/{id}/initiate-delivery
- Updates status to DELIVERY_INITIATED
** Admin marks as delivered: PUT /api/orders/{id}/mark-delivered
- Updates status to DELIVERE
